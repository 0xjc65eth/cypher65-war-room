# C65-09–10: operational labels and navigation (Issue #738)

Base: master 39fa95b5833ea0f61c8f578df1cabb388d8a61e4. Public navigation on 03/10/2026 opened all 13 modules; Admin settled as RESTRICTED and Rentals as Credentials required. No login, purchase, production mutation, scan or physical command was attempted.

C65-09 was not reproduced: the first Fleet click selected the visible panel while the initial snapshot remained pending, at 1440×900, 1280×800, 768×1024 and 390×844. API 401/403/429/500 did not prevent Fleet or Docs navigation. Harness mistakes (missing module-title ID and off-screen mobile links) were corrected before attributing failures to the app.

Confirmed additional defects: at 390 px, non-wrapping Fleet controls and the closed AI drawer extended the document width. The AI trigger was not bound when scripts ran with an already-ready DOM because initialization preceded its extension. Its input/send controls also had no chat binding. Closed drawer inputs could be reached off-screen; opening did not focus input or support Escape. A global reduced-motion duration of 0.01 ms delayed inherited visibility and defeated immediate focus.

Fix: wrap Fleet controls, bound the AI drawer to the viewport and hide it while closed, initialize after extension, focus after the next frame, restore trigger focus on close/Escape and remove drawer transitions with reduced motion. Bind drawer chat through the existing implementation and licensing gates; label local fallback as a local guide with snapshot context, without pretending a provider replied. Replace HOST CORE/COLONY/enterprise/institutional decorative labels with operational PT-BR names. Correct the market footer from BTC/PH/day to the actual BTC/TH/day scale. IDs, existing data contracts, brand and auth remain unchanged. This is limited copy cleanup, not complete internationalization or a typography redesign.

Validation: corrected baseline had 14 passes and 6 expected failures (two dashboard tests copied temporarily for visual comparison, two overflow tests, two labels tests). Independent drawer keyboard test subsequently failed before its binding/focus fix. Final affected browser suite: 29 passed, 1 deliberately skipped duplicate mobile-project viewport test. Unaffected wallet/advisory/dry-run/what-if cases passed in the wider journey run. Two old harness defects were corrected: Fleet fixtures now block service workers; the topbar guard includes the temperature metric added after that test, with an explicit temperature-ID assertion. No assertion was removed. Combined frontend gates passed; final run is in the delivery report.

Self-review (not independent approval): Frontend — no body overflow masking, CSS scoped to Fleet/drawer, DOM ownership retained; Accessibility/Motion — closed drawer hidden, keyboard open/close/focus and reduced motion asserted, transform replaces right-property transition; Security — no permissions/commands/credentials changed; QA — visible postconditions, fixtures isolated and original source used. Four viewport checks are not a full WCAG certification or a real 200% browser zoom measurement. No user research or performance SLO was established. Rollback: reviewed revert PR; merge/deploy and independent review pending.
