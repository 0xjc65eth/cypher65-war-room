## Interaction and motion

Section links are derived from real, visible sections owned by the active module/tab. IDs are unique and existing controls/destinations stay reachable. Navigation focuses the actual section, opens collapsed panels and closed disclosures through their visible summary, and scrolls instantly. Obsolete module callbacks cannot reopen another module; section targets are built synchronously after visibility changes. Both Support navigation entry points focus its close control on open. Count animations cancel immediately on replacement, unknown, reduced-motion and session reset; stale callbacks verify per-element ownership before writing. Source text wraps on narrow viewports; the populated Live 24-cell raster uses shrinkable grid tracks after a measured 406 px overflow on a 375 px viewport; existing tokens and keyboard focus styles are reused. New charts use 180 ms animation, disabled under reduced motion. Each device chart has one owner and is destroyed before replacement/error/empty/session reset. Primary Fleet counts use nonnegative safe integers: missing/invalid counts are unknown, never green zero or undefined online; confirmed empty remains distinct. Zero measurements and isolated observations among gaps receive visible markers; temperature and efficiency have separate axes.

## Architecture decisions (/advisor)

| Problem | Alternatives | Risk | Recommendation and reason | Acceptance evidence |
|---|---|---|---|---|
| Source failures appeared as successful empty results | Global data layer rewrite / limited existing reader repairs | A rewrite expands API and lifecycle impact | Keep independent existing source readers, classify HTTP/schema failures explicitly and version responses; preserves endpoint/stack compatibility | Real-fragment failure/recovery cases, session switches and retained-cache assertions |
| Older session JSON could restore private data or controls | Abort only / epoch and identity checks after JSON | Abort alone cannot revoke already parsed callbacks | Check session identity/generation at asynchronous boundaries and clear private evidence; one canonical owner for control status | Late response, late JSON, logout/tenant switch and competing writer regressions |
| 14 pages needed contextual navigation | New routes/layout framework / links to existing visible sections | New routes break controls and increase migration scope | Derive real section targets under existing visibility/tab rules, focus/open the target and retain IDs | Desktop/mobile, dark/light, reduced/full motion across all 14 modules |
| Single/isolated zeros disappeared and units shared an axis | Fill gaps or invent points / preserve observations with markers and separate axes | Filled gaps falsely imply continuity | Keep null gaps, finite real zeros and isolated markers; destroy replaced charts | Zero/sparse series, device request ordering, unit-axis and HTTP failure cases |
