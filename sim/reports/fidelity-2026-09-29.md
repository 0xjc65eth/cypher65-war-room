## Counterevidence and residual gaps

- The CIDR-cap test uses a generator that raises when consumed beyond the cap.
  Negative AxeOS tests reject example router/NAS/Home Assistant JSON. Neither
  proves all false positives are impossible.
- The full Fleet oracle compares IP, model, MAC, H/s, accepted shares and uptime
  against the virtual device state. It is strict for those fields only.
- A successful loopback run is not evidence of physical LAN reachability or a
  Docker Desktop VM route. No physical network topology was run.
- No physical captures from Bitaxe, NerdQaxe or an industrial ASIC exist in
  this repository. The BitMaker board README commit could not be resolved; the
  separate NerdQAxePlus firmware and ESP-Miner/cgminer sources are pinned in
  YAML catalog records. A pinned source is still not every firmware binary.
- No official Braiins REST contract, Stratum miner↔pool run, submitted-share
  hash verification, thermal/electrical physics, fake clock, seeded RNG,
  mutation campaign, LAN namespace, DHCP/mDNS/VLAN/fault model, or scale test
  (1/10/100/254 devices) was completed.
- No installer/service manager was installed or started. Windows support and
  macOS/Linux background service behavior are not proven here.
