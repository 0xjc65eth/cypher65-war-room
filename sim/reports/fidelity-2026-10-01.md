## Boundaries and remaining work

- The integration harness binds only `127.0.0.1` on an ephemeral port, stubs
  `_local_ipv4_addresses`, uses Flask's in-process test client, and stores data
  under pytest's temporary directory. It does not call public pools, Render,
  DNS, Docker, a physical LAN, or a real miner.
- The standalone virtual hardware test includes an oracle counterexample for
  accidentally reporting GH/s magnitude in an H/s field. This proves the
  oracle rejects that one regression, not general simulator fidelity.
- The E2E's restart command targets only its ephemeral `127.0.0.1` listener;
  the virtual device emits one 503 during reboot. An empty heartbeat preserves
  last-good data, then recovery updates the authenticated Fleet listing. No
  physical command or external network is involved.
- No physical response captures, thermal/electrical calibration, real
  share-validation round trip, Stratum miner↔pool integration, fake clock,
  richer fault schedules, LAN/Docker topology, or scale test is delivered here.
- Issue #386's physical matrix and owner-approved captures remain external
  prerequisites. Existing Stratum V1/V2 test servers are separate facilities
  and are not connected to this virtual miner.

This package is a bounded contract-lab delivery for the live #670 acceptance
criteria. It is not a substitute for the physical captures, pool integration,
or topology proof intentionally tracked as separate gaps.
